# Procedimientos

Punto de entrada para tareas concretas. Cada procedimiento debe incluir:

- objetivo y alcance;
- resumen de productos, lubricantes y fijadores necesarios;
- riesgos y precauciones;
- pasos ordenados;
- enlaces a las fichas del core;
- particularidades por vehículo, cuando existan.

!!! info
    Los procedimientos no duplican la explicación técnica de un producto. Enlazan a su ficha correspondiente.
