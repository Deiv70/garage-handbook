# Vehículos

Conocimiento específico de grupos, plataformas, componentes compartidos y modelos concretos.

## Organización

```text
vehicles/
├── VAG/
│   ├── shared/
│   └── Seat-Leon_1M/
└── PSA/
    └── shared/
```

La información reutilizable entre modelos se guarda en `shared/`. Cada carpeta de vehículo contiene únicamente sus especificaciones, variantes, compatibilidades, procedimientos particulares y modificaciones documentadas.
