# Lubricantes y grasas

Esta sección distinguirá entre:

- grasas lubricantes;
- pastas antigripantes;
- lubricantes sólidos;
- aceites penetrantes;
- lubricantes de silicona y PTFE;
- productos de montaje.

Las fichas incluirán espesante, aceite base, grado NLGI, aditivos, temperatura, resistencia al agua y carga, compatibilidad con elastómeros/plásticos y aplicaciones recomendadas o prohibidas.
