# Productos químicos

Clasificación por **composición**, **mecanismo de limpieza**, **propósito**, **agresividad** y **compatibilidad de materiales**.

## Familias previstas

- Champús y prelavados.
- APC y limpiadores alcalinos.
- Limpiadores con disolventes.
- Limpiafrenos.
- Descontaminantes férricos.
- Limpiadores ácidos y minerales.
- Eliminadores de alquitrán, adhesivos y resinas.
- Limpiacristales.
- Protectores, sellantes y coatings.
- Pulverizadores y compatibilidad química.

Cada ficha debe indicar pH cuando sea aplicable, necesidad de aclarado, residuos, inflamabilidad, compatibilidad con protecciones y recipiente adecuado.
