# Materiales

Referencia de compatibilidad química y mecánica para:

- pintura, barniz, coatings, PPF y vinilo;
- acero, inoxidable, aluminio, cobre, latón y zincados;
- ABS, PP, PE/HDPE, PA, POM, PVC y PTFE;
- EPDM, NBR, FKM/Viton y silicona.

Cada ficha indicará los productos compatibles, las exposiciones condicionadas y los químicos que deben evitarse.
