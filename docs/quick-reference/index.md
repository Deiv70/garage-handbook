# Quick Reference

Esta sección ofrece respuestas rápidas para consultar durante un trabajo, comparar opciones o tomar una decisión inicial.

!!! warning "No es la fuente de verdad"
    Las páginas de Quick Reference resumen información mantenida en **Knowledge**, **Vehicles** y **Procedures**. Ante una duda, prevalece la ficha técnica enlazada y la documentación del fabricante.

## Formatos

- **Cheat Sheets:** tablas y resúmenes compactos.
- **Decision Trees:** selección guiada mediante preguntas.
- **Compatibility:** matrices de compatibilidad entre productos, recipientes, materiales o protecciones.
- **Comparisons:** diferencias entre familias o productos concretos.
- **Checklists:** comprobaciones antes, durante y después de un trabajo.
- **Torque Tables:** valores de apriete con su fuente y aplicabilidad exacta.

## Principio de mantenimiento

Quick Reference debe enlazar siempre las fuentes que resume. Cuando una vista no pueda generarse automáticamente, se marcará con `manual_sync_required: true` y deberá revisarse al modificar las fichas relacionadas.
