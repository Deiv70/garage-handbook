# Componentes

Componentes de automoción reutilizables entre distintos vehículos.

Aquí se documenta el funcionamiento general de elementos como una pinza de freno, un servofreno, un cilindro maestro o un turbocompresor. Las referencias OEM y variantes concretas pertenecen a la sección del vehículo correspondiente.
