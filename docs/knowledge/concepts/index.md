# Conceptos

Fundamentos transversales utilizados por el resto del handbook: presión, vacío, pH, viscosidad, fricción, corrosión, temperatura, par y otros conceptos técnicos.

Esta sección explica **qué significa cada concepto y cómo condiciona una decisión técnica**, sin ligarlo a un vehículo o producto concreto.
