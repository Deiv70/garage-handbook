# Lubricantes y grasas

Aceites, grasas, pastas y aerosoles destinados a reducir fricción, evitar desgaste, proteger frente a corrosión o facilitar el montaje.

Las fichas distinguirán, cuando proceda, el aceite base, el espesante, el grado NLGI, los aditivos, la resistencia al agua, el rango térmico y la compatibilidad con materiales.
