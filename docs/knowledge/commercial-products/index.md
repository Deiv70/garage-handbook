# Productos comerciales

Fichas de productos concretos disponibles en el mercado.

Cada producto debe enlazar con el concepto técnico que implementa. Por ejemplo, Koch Chemie Green Star se relacionará con la categoría APC, y Grafen Limpiafrenos con la categoría limpiafrenos.

Las marcas son ejemplos y recomendaciones contextuales, no la estructura principal del conocimiento.
