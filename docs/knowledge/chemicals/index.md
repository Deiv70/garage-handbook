# Productos químicos

Familias químicas empleadas para limpiar, descontaminar, desengrasar, proteger o preparar superficies.

La organización se basa primero en la **función y composición** del producto —por ejemplo APC alcalino, limpiafrenos con disolventes o descontaminante férrico— y después muestra productos comerciales como ejemplos.
