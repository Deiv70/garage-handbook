# Garage Handbook

Manual técnico personal de automoción orientado a procedimientos, productos químicos, lubricación, compatibilidad de materiales y fijadores.

> [!WARNING]
> Esta documentación es una referencia práctica. Antes de aplicar un producto, confirma siempre la ficha técnica, la ficha de datos de seguridad y las instrucciones del fabricante del vehículo o componente.

## Principios de organización

- Los **procedimientos** son el punto de entrada y resumen qué hace falta.
- Las fichas de **productos químicos** explican composición, pH, agresividad, propósito y compatibilidades.
- Las fichas de **lubricantes** distinguen grasas, pastas antigripantes, aceites y aerosoles.
- La sección de **materiales** permite comprobar compatibilidad con pintura, barniz, PPF, vinilo, elastómeros, plásticos y metales.
- Las marcas y productos comerciales aparecen integrados en la categoría técnica correspondiente, no como una sección independiente.

## Leyenda de compatibilidad

| Símbolo | Significado |
|---|---|
| ✅ | Compatible en uso normal siguiendo las instrucciones |
| ⚠️ | Compatible con condiciones, prueba previa o exposición limitada |
| ❌ | Evitar |
| ❓ | Depende de la formulación; consultar fabricante |

## Escala de agresividad

| Nivel | Interpretación |
|---:|---|
| 1/5 | Muy suave; mantenimiento habitual |
| 2/5 | Suave, pero puede degradar protecciones con uso repetido |
| 3/5 | Limpieza intensa; controlar dilución y tiempo de contacto |
| 4/5 | Agresivo; uso localizado y prueba previa |
| 5/5 | Muy agresivo o industrial; requiere compatibilidad confirmada y EPI adecuados |
